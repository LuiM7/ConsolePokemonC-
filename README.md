# Pokémon Data Structures — C#
Juego de consola temático de Pokémon desarrollado en C# para demostrar el uso práctico de las principales estructuras de datos genéricas de .NET.

Objetivo
Aplicar de forma práctica las estructuras de datos List<T>, Queue<T> y Stack<T> dentro de un contexto de juego, haciendo el aprendizaje más dinámico e interactivo.

Estructuras de datos utilizadas
EstructuraUso en el juegoList<T>Inventario de Pokémon capturadosQueue<T>Cola de batalla (turno por turno)Stack<T>Historial de acciones (deshacer movimientos)

Tecnologías
C# .NET Consola

Cómo ejecutar

Compila y ejecuta:

bash   dotnet run

Requiere .NET SDK instalado.


📁 Estructura del proyecto
pokemon-csharp/
├── Program.cs          # Punto de entrada
├── Pokemon.cs          # Clase Pokémon
├── Inventario.cs       # Lógica con List<T>
├── ColaDeBatalla.cs    # Lógica con Queue<T>
├── Historial.cs        # Lógica con Stack<T>
└── pokemon-csharp.csproj
